Documents to upload

A step done once the new hire did it

Features

What it does

  • ✓  An Upload a Document step, of a document type of the employees (e.g. Passport).
  • ✓  When the pre-boarding starts, the document waits in the documents of the employee; the new hire uploads the file from their documents page on the website.
  • ✓  The step is done once a file is uploaded; HR checks the document in HR Documents as usual.
Setup

Configuration

Employees > Configuration > Pre-boarding Steps: add a step Upload a Document and choose its document type.

Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise.

Install

Dependencies

om_hr_preboarding, om_hr_document, om_hr_portal_document. It installs by itself once they are all installed.
