Features

What it does

✓  The validated overtime of the employee up to the end of the period, not paid yet, is paid by the *Overtime* rule (OVERTIME, category Allowance): hours x hourly wage x the salary rate of the time rule, or of the type of an attendance entered by hand. An overtime whose attendance changed since waits for the time rules to compute it again.
✓  The hourly wage is the one of an hourly contract, else the monthly wage / the days per month of the payroll settings (30 by default, or e.g. 21.67) / the hours per day of the working schedule.
✓  Each hour is paid once: it is linked to the payslip paying it, and becomes payable again if that payslip is cancelled or refunded. Overtime validated after its month is paid on the next payslip.
✓  The Overtime tab of the payslip lists what it pays; the attendances list has an optional *Paid On* column for the payroll officers.
✓  New salary structures pay the overtime: the base structure gets the rule. Add the Overtime rule to your own structures.
Setup

Configuration

✓  Attendances > Configuration: the time rules and their salary rate.
✓  Payroll > Configuration > Settings > Worked Days: the days per month of the daily wage.
✓  With *Overtime Pre-Approval*, only the overtime authorised or accepted by the manager is validated, so only that is paid.
Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise. On Enterprise, it cannot be installed together with the Enterprise Payroll app: both define the same records. Use one or the other.

Install

Dependencies

om_hr_payroll, hr_attendance. It installs by itself once they are all installed.
