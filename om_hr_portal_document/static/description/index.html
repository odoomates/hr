Features

What it does

  • ✓  A Documents card on My HR opens /my/hr/documents: a card per document of the employee, with the type, the number, the expiry date (coloured when it is expiring or expired) and the files to download.
  • ✓  Send: the employee uploads the renewed passport or permit. The file is added to the document, a message is posted on it, and HR checks it and updates the dates.
  • ✓  Each employee sees only their own records: changing an id in the address gives a page not found, not someone else's record.
Use

How it works

  • 1.  The employee opens My HR > Documents.
  • 2.  On a document to renew, they choose the new file and click Send.
