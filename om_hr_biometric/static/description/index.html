Two ways to connect

ADMS or TCP?

Use ADMS when your device has it: punches in real time and nothing to open on your network. Use TCP for the devices without it. You can mix both, device by device.

  In this app

ADMS (push)

The device calls Odoo over HTTP and sends each punch as it happens.

✓  No fixed IP address, no port to open, the device can be anywhere with internet.
✓  Punches within seconds; commands collected by the device when it calls.
✓  Works with Odoo on premise and on Odoo.sh (the device must accept a domain name).
✓  Look for Menu → Communication → Cloud Server Setting on the device.
  Free add-on

TCP (pull)

Odoo connects to the device at its IP address on port 4370 and reads it.

✓  For the devices without ADMS, or on a network they cannot leave.
✓  TCP or UDP, with the communication key of the device.
✓  New punches read every 10 minutes, or at once with Download Now.
✓  The Odoo server must reach the device: same network, VPN or a forwarded port.
Get the TCP/UDP add-on →

Features

A closer look

Punches

Every punch, the right check-in or check-out

✓  Each punch kept once, as the device sent it, then processed in the order of time.
✓  Status Codes mode: check in, check out, break and overtime, with your own code table.
✓  Check-In Only and Check-Out Only for separate entry and exit devices.
✓  Unknown users wait, processed once linked; no employee is ever created by a device.
✓  Process Again a period: the attendances of the devices made again, those by hand kept.
Devices

Managed from Odoo

✓  A dashboard of the devices: online or not, punches of the day, users linked or not.
✓  A setup checklist on each new device, from the first contact to the first punches.
✓  Device users matched to the employees by ID, by name, or by the start of the name.
✓  Employees sent with their fingerprints from another device: no need to enroll again.
✓  Employees without a Biometric ID get the next free number when sent.
✓  Restart a device, set its clock, read its model, firmware and counters.
✓  Download the punches of a period again, e.g. after a network outage.
✓  Every command queued until the device calls, retried, with its reply.
Reports

See who came and who did not

✓  Attendance Status: each day against the working schedule, time off and public holidays.
✓  Monthly Attendance Sheet in PDF: on time, late, left early, absent, missing check-out.
✓  Today: a board of who is at work, late, not arrived yet or absent.
✓  Absences, and the first and last punch of each employee, day by day.
✓  Punch analysis by device, day and verification: finger, face or card.
Trust

Built for attendance and biometric data

✓  Only devices with a known serial number are heard; optional allowed IP addresses.
✓  Managers configure the devices; administrators follow the punches; nobody else sees them.
✓  Attendances show their check-in and check-out device.
✓  No external Python library to install.
Guide and install

Get started

Set up a device with ADMS

Five minutes, the device pushing its punches.

1In Odoo, Attendances → Biometric → Configuration → Devices: a name, the serial number (on the device, Menu → System Info → Device Info), the timezone and the mode, Alternate when the employees choose no status.
2On the device, Menu → Communication → Cloud Server Setting: the domain name of Odoo (or its IP address on the local network), port 443 with HTTPS, 8069 on the local network.
3Within a minute the device is Online. Give each employee the Biometric ID they have on the device, or Send Employees from Odoo.
4Punch: the check-ins and check-outs appear in Attendances within seconds.
Several databases on the server? The domain name must select the database (dbfilter): the device cannot choose it. Behind a proxy, keep HTTPS and fill Allowed IP Addresses.

Set up a device over TCP

For a device without ADMS: install the TCP/UDP add-on first.

1On the device, a fixed IP address (Menu → Communication → Ethernet) and the communication key (Menu → Communication → PC Connection, 0 when none).
2Odoo must reach the device on port 4370: same network, VPN or a port forwarded by the router.
3In Odoo, a device with the TCP (Pull) protocol, its IP address, port and key, then Test Connection.
4Download Now, or wait: Odoo reads the new punches every 10 minutes.

Then, once for all the devices

In Odoo.

1Attendances → Configuration: the maximum shift (16 hours by default), and whether Odoo keeps the biometric templates.
2Employees: their Biometric ID (employee form, HR Settings tab), or Send Employees from the device.
3Follow Attendances → Biometric → Punches for unknown users and errors, and the attendances To Review.

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search Biometric Attendance Machine and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves these modules half loaded, ending on a missing field or view error.
Still failing? Write to odoomates@gmail.com with your Odoo version and the error.
