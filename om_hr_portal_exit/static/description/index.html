Features

What it does

  • ✓  A Resignation card on My HR opens /my/hr/resignation.
  • ✓  Hand In My Resignation: the date the notice is given, a note, and a box to tick to confirm. The exit is created and submitted for approval; an employee with an exit already in progress cannot hand in a second one.
  • ✓  While the exit is in progress: its status, the notice date, the last working day, the step it waits for, and each clearance line, done or pending.
  • ✓  Each employee sees only their own records: changing an id in the address gives a page not found, not someone else's record.
Use

How it works

  • 1.  The employee opens My HR > Resignation, fills in the form, ticks the box and confirms.
  • 2.  They come back to the same page to follow the approval and the clearance.
Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise. On Enterprise, it cannot be installed together with the Enterprise Approvals app: both define the same records. Use one or the other.

Install

Dependencies

om_hr_portal, om_hr_exit. It installs by itself once they are all installed.
