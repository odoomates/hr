# Getting help

| You want to… | Go to |
|---|---|
| Ask how to install, configure or use a module | [odoomates@gmail.com](mailto:odoomates@gmail.com) |
| Report a bug | [Issues → Bug report](https://github.com/odoomates/hr/issues/new/choose), or [odoomates@gmail.com](mailto:odoomates@gmail.com) |
| Suggest a new feature or an improvement | [Issues → Feature request](https://github.com/odoomates/hr/issues/new/choose) |
| Help: review, fix, translate | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a security vulnerability | Email, never a public issue: see [SECURITY.md](SECURITY.md) |
| Get support, customisation or a new module | [odoomates@gmail.com](mailto:odoomates@gmail.com) |

## Before you ask

- Read the description page of the module (on the Odoo App Store or in
  `static/description/index.html`) and its `README.rst`. Payroll comes with a user
  guide: `om_hr_payroll/static/description/user_guide.pdf`.
- Search the [issues](https://github.com/odoomates/hr/issues?q=is%3Aissue), open
  and closed: your question may already have an answer.
- Update to the latest commit of your branch: the problem may already be fixed.

The help on GitHub is given for free, when the maintainers have time. There is
no guaranteed answer time.
