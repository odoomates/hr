Features

What it does

✓  The My HR menu: each Odoo Mates HR module adds there what the employees do for themselves, such as their loans, certificates, documents, assets, appraisals and payslips. Every internal user sees it; the menu shows once a module adds an entry to it.
✓  The Employee Category of the contract (required, the first employee type by default), on the contract form next to the job.
✓  The Employee Types menu in Employees > Configuration, in debug mode.

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise.
