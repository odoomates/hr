Features

What it does

  • ✓  The deduction is negative, so the loan account of the loan type is set as the debit account of the Loan Installments rule, which credits it; its other side is the account the net salary is taken from (the debit account of the Net rule). This happens when a loan type is created with a loan account, or its loan account changes. Accounts already set on the rule are kept.
  • ✓  The payslip lines on a loan account carry the employee (their work contact) as partner, like the payments of the loans.
  • ✓  The loan account is reconciled per employee once the payslips, or their batch, are posted.
Setup

Configuration

  • ✓  Set the loan account on the loan types (HR Loans in Accounting), and the accounts of the Net rule (Payroll Accounting). The Loan Installments rule is one for all the loan types: it gets the first loan account set and keeps it. Check its accounts in Payroll > Configuration > Salary Rules.
Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise. On Enterprise, it cannot be installed together with the Enterprise Approvals and Payroll apps: both define the same records. Use one or the other.

Install

Dependencies

om_hr_loan_account, om_hr_loan_payroll, om_hr_payroll_account. It installs by itself once they are all installed.
