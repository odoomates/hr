What they hold

Each asset handed over to them, with its serial number

Handed over and returned

The dates and the status of each assignment

Only their own

Each employee sees only the assets assigned to them

Features

What it does

✓  An Assets card on My HR opens /my/hr/assets: each assignment of the employee, with the asset, the serial number, the date handed over, the date returned and the status (returned, lost...).
✓  Read only: HR hands over and takes back the assets in the backend.
✓  Each employee sees only their own records: changing an id in the address gives a page not found, not someone else's record.
Use

How it works

The employee opens My HR > Assets on the portal.

Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise.

Install

Dependencies

om_hr_portal, om_hr_asset. It installs by itself once they are all installed.
