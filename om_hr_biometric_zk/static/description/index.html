Features

A closer look

Over the network

Odoo reads the device

✓  The new punches processed like the pushed ones: modes, repeated punches, forgotten check-outs.
✓  Device users, clock, restart and enrollment, through one connection.
✓  A device that cannot be reached shows its last error and is Offline; the others go on.
Peace of mind

Never in the way

✓  The device keeps taking punches while Odoo reads it.
✓  Clear Punches on Device for the attendance managers, after a full download, or by itself above a number of punches, the device locked from the reading to the clearing.
✓  Uninstall at any time: the devices are archived, their punches stay.
Guide and install

Get started

Set up your device

Five minutes, over TCP.

1On the device, a fixed IP address (Menu → Communication → Ethernet) and the communication key (Menu → Communication → PC Connection, 0 when none).
2Odoo must reach the device on port 4370: same network, VPN or a port forwarded by the router.
3In Odoo, a device with the TCP (Pull) protocol, its IP address, port and key, then Test Connection.
4Download Now, or wait: Odoo reads the new punches every 10 minutes.
For punches in real time, or a device Odoo cannot reach, use ADMS (in Biometric Attendance Machine).

How to install it

1Copy the module to a folder of your own modules, e.g. /opt/odoo/custom-addons, and add that folder to addons_path in odoo.conf.
2Restart Odoo.
3Activate the developer mode, then Apps → Update Apps List.
4Clear the Apps filter, search Biometric Attendance Machine - TCP/UDP and install it.
Do not use Apps → Import Module. It is meant for data modules without Python, and leaves these modules half loaded, ending on a missing field or view error.
Still failing? Write to odoomates@gmail.com with your Odoo version and the error.
