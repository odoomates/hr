Features

What it does

✓  Each line of a merit cycle shows the rating of the last appraisal done of the employee.
✓  The merit matrix gives the raise suggested for each rating by where the wage sits in its band: a better rating gets more, and a wage already high in its band gets less, so that the wages move towards the midpoint. Generating a merit cycle fills each proposal with it; the managers then adjust them.
✓  A starting matrix is installed for the ratings of HR Appraisals, e.g. 5% for Exceeds Expectations in the lower third of the band. A company may have its own matrix, which wins over the shared one.
Setup

Configuration

Employees > Configuration > Merit Matrix (HR administrators).

Editions

Community and Enterprise

Works with Odoo 20 Community and Odoo 20 Enterprise. On Enterprise, it cannot be installed together with the Enterprise Appraisals app: both define the same records. Use one or the other.
